# Dynamic Task Manager

A simple React task management application built as part of the React Course Sessions 1 & 2 assignment.

## Features

* Add, complete, and delete tasks
* Filter tasks by status
* View task statistics
* Clear completed tasks
* Responsive and clean UI

## Tech Stack

* React
* JavaScript
* CSS
* Vite

## Concepts Practiced

JSX • Components • Props • Events • useState • Conditional Rendering • map() • Keys
